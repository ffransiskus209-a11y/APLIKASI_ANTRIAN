## 📖 User persona
#### User persona customer: 1. Menggunakan layanan antrean, 2. Mengambil nomor antrean, 3. Melihat posisi antrean, 4. Menerima notifikasi, 5. Membatalkan antrean.User persona admin: 1. Mengelola layanan antrean, 2. Melihat antrean masuk, 3. Memanggil nomor antrean, 4. Mengubah status antrean, 5. Mengelola daftar layanan.

## 📖 User story customer
- Sebagai Customer, saya ingin melakukan registrasi agar dapat memiliki akun dan menggunakan QueueApp.
- Sebagai Customer, saya ingin login agar dapat mengakses fitur QueueApp.
- Sebagai Customer, saya ingin memilih layanan agar dapat mengambil antrean sesuai kebutuhan saya.
- Sebagai Customer, saya ingin mengambil nomor antrean agar dapat mendapatkan giliran pelayanan.
- Sebagai Customer, saya ingin melihat status dan posisi antrean agar mengetahui perkembangan antrean saya.
- Sebagai Customer, saya ingin menerima notifikasi agar mengetahui ketika antrean saya mendekati atau tiba pada giliran pelayanan.
- Sebagai Customer, saya ingin membatalkan antrean agar dapat membatalkan antrean ketika saya tidak jadi menggunakan layanan.
