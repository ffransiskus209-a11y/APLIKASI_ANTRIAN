# Requirements — QueueApp

## 1. Problem Statement

QueueApp merupakan aplikasi antrean sederhana yang digunakan untuk membantu pengguna dalam proses antrean secara lebih terstruktur.

## 2. Solusi yang Diusulkan

QueueApp menyediakan sistem antrean digital yang membantu pengunjung dan petugas dalam mengelola proses antrean.

## 3. Pengguna

- Pengunjung
- Petugas

## 4. Batas MVP

MVP mencakup fungsi utama yang diperlukan untuk membangun sistem antrean secara bertahap selama perkuliahan.

## 5. Yang Sengaja TIDAK Dibuat

Fitur di luar kebutuhan utama QueueApp tidak dibuat pada tahap awal.

## 6. Arsitektur Awal

QueueApp menggunakan arsitektur yang terdiri dari client web, server/API, dan database MySQL.

## 7. Environment Pengembangan

Pengembangan menggunakan Docker Compose dengan service:

- MySQL
- Server
- Web
